# 홈체력100 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 카메라로 국민체력100 공식 종목(교차윗몸일으키기·의자에앉았다일어서기)을 자동 측정하고, 공단 측정결과 데이터 기준 백분위·체력나이·처방을 보여주는 정적 웹앱을 오늘 24시 전에 GitHub Pages에 배포한다.

**Architecture:** 빌드 전 Node 스크립트가 공단 API 원본(`data-raw/`)을 집계해 `public/data/*.json`을 만든다. React SPA가 이 JSON과 브라우저 내 MediaPipe PoseLandmarker를 사용한다. 서버 없음.

**Tech Stack:** Vite 7 + React 19 + TypeScript, Tailwind CSS 4, @mediapipe/tasks-vision, Vitest, GitHub Pages(Actions).

## Global Constraints

- 마감: 2026-10-02 24:00 (KST). 배포 URL은 가장 먼저 확보한다.
- API 키는 `.env`에만. `data-raw/`, `.env`는 git 제외. 배포물에 키가 들어가면 안 된다.

- 영상·카메라 프레임은 기기 밖으로 전송하지 않는다.
- Vite `base`는 `/homefit100/` (저장소 이름 `homefit100`).

### Task 2: 각도·반복 카운터 (TDD)

**Files:** Create `src/lib/geometry.ts`, `src/lib/repCounter.ts`, `src/lib/tests.ts`; Test `tests/repCounter.test.ts`

**Interfaces (Produces):**
```ts
// geometry.ts
export type Pt = { x: number; y: number; visibility?: number };
export function angleDeg(a: Pt, b: Pt, c: Pt): number; // b가 꼭짓점, 0~180

// repCounter.ts
export type RepCounterConfig = { downBelow: number; upAbove: number; startPhase: 'down' | 'up'; countOn: 'up' | 'down'; alpha: number };
export type RepCounter = { update(angle: number | null): { count: number; phase: 'down' | 'up'; smoothed: number | null }; reset(): void };
export function createRepCounter(cfg: RepCounterConfig): RepCounter;

// tests.ts
export type TestId = 'situp' | 'chairstand';
export type TestDef = { id: TestId; name: string; field: 'item_f019' | 'item_f023'; durationSec: number; unit: '회';
  joints: [number, number, number][]; // MediaPipe 인덱스 (좌/우 후보), 가시성 높은 쪽 사용
  counter: RepCounterConfig; guide: string[] };
export const TESTS: Record<TestId, TestDef>;
export function testForAge(age: number): TestId; // 65세 이상 chairstand, 그 외 situp
```

카운트 규칙: 각도가 `downBelow` 아래로 내려가면 phase=down, `upAbove` 위로 올라가면 phase=up. `countOn` 상태로 전이될 때 +1. 사이 구간(히스테리시스)에서는 상태 유지. `null`(가시성 부족)은 무시.
- 교차윗몸일으키기: 어깨-엉덩이-무릎 각. 누움 ≈ 140°+, 일어남 ≈ 70°- → `{ downBelow: 75, upAbove: 120, startPhase: 'up', countOn: 'down', alpha: 0.5 }` (각이 작아짐 = 상체 일으킴 = 1회)
- 의자앉았다일어서기: 엉덩이-무릎-발목 각. 앉음 ≈ 90°, 섬 ≈ 165°+ → `{ downBelow: 115, upAbove: 155, startPhase: 'down', countOn: 'up', alpha: 0.5 }`

- [ ] 테스트 작성:
```ts
import { describe, it, expect } from 'vitest';
import { angleDeg } from '../src/lib/geometry';
import { createRepCounter } from '../src/lib/repCounter';
import { TESTS, testForAge } from '../src/lib/tests';

const feed = (c: ReturnType<typeof createRepCounter>, xs: (number | null)[]) => xs.map((x) => c.update(x)).at(-1)!;

describe('angleDeg', () => {
  it('직각', () => expect(angleDeg({ x: 1, y: 0 }, { x: 0, y: 0 }, { x: 0, y: 1 })).toBeCloseTo(90));
  it('일직선', () => expect(angleDeg({ x: -1, y: 0 }, { x: 0, y: 0 }, { x: 1, y: 0 })).toBeCloseTo(180));
});

describe('repCounter', () => {
  it('윗몸일으키기 3회', () => {
    const c = createRepCounter({ ...TESTS.situp.counter, alpha: 1 });
    expect(feed(c, [150, 60, 150, 60, 150, 60, 150]).count).toBe(3);
  });
  it('히스테리시스 구간 떨림은 세지 않음', () => {
    const c = createRepCounter({ ...TESTS.situp.counter, alpha: 1 });
    expect(feed(c, [150, 100, 110, 95, 115, 100]).count).toBe(0);
  });
  it('null 무시', () => {
    const c = createRepCounter({ ...TESTS.chairstand.counter, alpha: 1 });
    expect(feed(c, [90, null, 170, null, 90, 170]).count).toBe(2);
  });
  it('reset', () => {
    const c = createRepCounter({ ...TESTS.chairstand.counter, alpha: 1 });
    feed(c, [90, 170]); c.reset();
    expect(c.update(90).count).toBe(0);
  });
});

describe('testForAge', () => {
  it('64→situp, 65→chairstand', () => { expect(testForAge(64)).toBe('situp'); expect(testForAge(65)).toBe('chairstand'); });
});
```

### Task 3: 데이터 집계 스크립트 + 규준 계산 (TDD)

**Files:** Create `scripts/build-data.mjs`, `src/lib/norms.ts`; Test `tests/norms.test.ts`; Output `public/data/norms.json`, `public/data/rx.json`, `public/data/centers.json`, `public/data/videos.json`, `public/data/courses.json`

**norms.json 형식:**
```ts
export type Sex = 'M' | 'F';
export type NormTable = {
  updated: string; sampleSize: number;
  tests: Record<TestId, Record<Sex, {
    ages: Record<string, { n: number; q: number[] }>;          // 나이(정수) → 101개 분위값 q[0..100], ±2세 창
    grades: Record<string, Record<'1등급' | '2등급' | '3등급', number>>; // 10세 연령대('20','30',..) → 등급별 중앙값
  }>>;
};
```
**Interfaces (Produces, norms.ts):**
```ts
export function percentile(q: number[], value: number): number;              // 0~100, 값 이하 비율(선형보간)
export function fitnessAge(ages: Record<string, { n: number; q: number[] }>, value: number, realAge: number): number;
  // 중앙값(q[50])이 value와 가장 가까운 나이, 동률이면 realAge에 가까운 쪽
export function estimateGrade(gradeMedians: Record<'1등급' | '2등급' | '3등급', number>, value: number): '1등급' | '2등급' | '3등급' | '참가';
export function ageBand(age: number): string; // 10세 단위 내림, '20'~'80'으로 제한 (19→'20', 93→'80')
```
**rx.json 형식:** `Record<TestId, Record<Sex, Record<band, Record<decile '0'..'9', {name: string; n: number}[]>>>>` (상위 8개)

**centers.json:** `{ name, addr, sido, recentCnt }[]` (센터명 기준 중복 제거, 최근 12개월 측정건수 합)
**videos.json:** `Record<운동명, { title, url, thumb, desc, tool, place }>`
**courses.json:** 등록시설 데이터가 있으면 `{ sido, sigungu, facil, item, course, price, days, time }[]`, 없으면 빈 배열

```ts
import { describe, it, expect } from 'vitest';
import { percentile, fitnessAge, estimateGrade, ageBand } from '../src/lib/norms';
const q = Array.from({ length: 101 }, (_, i) => i); // 값 = 분위
describe('norms', () => {
  it('percentile 중간값', () => expect(percentile(q, 50)).toBeCloseTo(50));
  it('percentile 범위 밖', () => { expect(percentile(q, -5)).toBe(0); expect(percentile(q, 500)).toBe(100); });
  it('fitnessAge: 중앙값이 가장 가까운 나이', () => {
    const ages = { '30': { n: 100, q: q.map((v) => v + 30) }, '40': { n: 100, q: q.map((v) => v + 20) }, '50': { n: 100, q: q.map((v) => v + 10) } };
    expect(fitnessAge(ages, 70, 30)).toBe(40); // 40세 중앙값 = 70
  });
  it('estimateGrade', () => {
    const g = { '1등급': 40, '2등급': 30, '3등급': 20 };
    expect(estimateGrade(g, 45)).toBe('1등급'); expect(estimateGrade(g, 31)).toBe('2등급');
    expect(estimateGrade(g, 20)).toBe('3등급'); expect(estimateGrade(g, 5)).toBe('참가');
  });
  it('ageBand', () => { expect(ageBand(19)).toBe('20'); expect(ageBand(47)).toBe('40'); expect(ageBand(93)).toBe('80'); });
});
```
