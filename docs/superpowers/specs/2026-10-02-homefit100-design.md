# 홈체력100 — AI 카메라 셀프 체력측정 & 처방 서비스 설계

- 작성일: 2026-10-02
- 목적: 2026 국민체육진흥공단 공공데이터 활용 경진대회 ① 서비스(앱·웹) 개발 부문 출품 (마감 10/2 24시)
- 한 줄 소개: 스마트폰 카메라 하나로 집에서 국민체력100 공식 종목을 측정하고, 300만 건 측정 데이터 기준 체력나이와 맞춤 처방을 받는다.

## 1. 심사기준 대응

| 기준 | 비중 | 대응 |
|---|---|---|
| 독창성 | 25% | 국민체력100 공식 종목을 브라우저 AI(자세추정)로 자동 측정하는 최초 서비스. 영상은 기기 밖으로 나가지 않음 |
| 실용성 | 20% | 인증센터 방문 없이 1차 측정 → 결과·처방 → 센터 정식 인증 유도 |
| 적절성 | 20% | 공단 API 4~5종을 측정 기준·처방·연계에 각각 명확한 역할로 사용 |
| 발전가능성 | 20% | 국민체력100 앱 모듈, 학교(PAPS)·기업 웰니스·건강증진형 보험·보건소 연계 |
| 기술성 | 15% | MediaPipe Pose 실시간 추론 + 자세 상태머신 카운터 |

## 2. 활용 데이터 (공공데이터포털, 국민체육진흥공단)

| 데이터 | 엔드포인트 | 역할 |
|---|---|---|
| 국민체력100 체력인증센터 측정결과 | `SRVC_NFA_TEST_RESULT/TODZ_NFA_TEST_RESULT_NEW` | 최신 약 20만 건으로 성별×연령 규준(백분위)표, 체력나이, 등급 분포, 비슷한 체력군의 실제 처방(pres_note) TOP N |
| 국민체력100 체력인증센터 측정건수 | `SRVC_TODZ_NFA_TEST_CENTER_CNT/TODZ_NFA_TEST_CENTER_CNT` | 인증센터 목록·주소·최근 측정건수 → 지역별 가까운 센터 안내 |

| 스포츠강좌이용권 등록강좌 | `SRVC_OD_API_FACIL_COURSE/todz_api_facil_course_i` | 약점 체력요인에 맞는 종목 강좌 추천 |
| 스포츠강좌이용권 등록시설 (선택) | `SRVC_OD_API_FACIL_MNG/todz_api_facil_mng_i` | 강좌의 시도·시군구·주소 (승인 시 사용) |

API 키는 `.env`(git 제외)에만 두고, 빌드 전에 스크립트가 원본(`data-raw/`, git 제외)을 받아 집계 JSON(`public/data/`)만 배포한다.

## 3. 측정 종목 (카메라 자동 카운트)

| 대상 | 종목 | 데이터 항목 | 측정 방식 |
|---|---|---|---|
| 성인 19~64세 | 교차윗몸일으키기 (60초) | `item_f019` | 측면 촬영, 어깨-엉덩이-무릎 각도로 상체 일으킴 판정 |
| 어르신 65세+ | 의자에앉았다일어서기 (30초) | `item_f023` | 측면 촬영, 엉덩이-무릎-발목 각도로 앉음/섬 판정 |

두 종목 모두 국민체력100 공식 측정 종목이며 측정결과 데이터에 기록이 충분하다(1천 건 중 각각 439건, 129건).

카운터는 관절 각도 기반 2상태(down/up) 상태머신이며, 히스테리시스(진입·이탈 임계값 분리)와 지수이동평균 평활화로 중복 카운트를 막는다. 관절 가시성(visibility)이 낮으면 카운트를 멈추고 "몸 전체가 보이게" 안내를 띄운다.

## 4. 화면 흐름

1. **랜딩**: 소개, [측정 시작], [운동 없이 체험하기(데모)]
2. **프로필**: 성별, 나이, 시도 → 나이로 종목 자동 결정, 키·몸무게(선택, BMI)
3. **측정**: 카메라 + 스켈레톤 오버레이 + 카운트 + 타이머. 대안: 영상 파일 업로드, 직접 입력
4. **결과**: 동성·동연령대 백분위, 예상 등급(1·2·3등급/참가), 체력나이, 분포 그래프
5. **처방**: 비슷한 체력군이 실제로 처방받은 운동 TOP5 + 공식 영상, 지역 인증센터, 이용권 강좌

데모 모드는 미리 녹화한 동작 영상을 같은 파이프라인에 넣어 운동 없이도 AI 측정 과정을 보여준다(심사위원용).

## 5. 계산 규칙

- **백분위**: 같은 성별 × 같은 연령(±2세 창, 표본 부족 시 5세 단위 연령대)의 측정값 분포에서 사용자 값 이하 비율.
- **체력나이**: 같은 성별에서 연령별 중앙값 곡선을 만들고, 사용자 값과 중앙값이 가장 가까운 연령. 측정 종목의 연령 범위(성인 19~64, 어르신 65~90)로 제한.
- **예상 등급**: 같은 성별·연령대에서 cert_gbn(1등급/2등급/3등급/참가)별 해당 종목 값의 분포를 보고, 사용자 값이 속하는 가장 높은 등급의 하위 경계를 넘는지로 추정. 단일 종목 기반 추정임을 화면에 명시.
- **처방 TOP5**: 같은 성별·연령대에서 사용자 백분위 ±10%p 구간 사람들의 pres_note를 운동명으로 분해해 빈도 상위 5개.

## 6. 기술 구성

- Vite + React + TypeScript, Tailwind CSS
- `@mediapipe/tasks-vision` PoseLandmarker(lite), WASM·모델은 CDN 로드
- 테스트: Vitest (카운터 상태머신, 규준 계산)
- 배포: GitHub Pages (`gh` CLI로 공개 저장소 생성, Actions로 `dist` 배포)

## 7. 예외 처리

- 카메라 권한 거부/미지원 → 영상 업로드 또는 직접 입력으로 전환
- 모델 로드 실패 → 직접 입력으로 전환, 결과·처방은 그대로 제공
- 표본 부족(해당 성별·연령 30건 미만) → 인접 연령대로 확장

## 8. 범위 밖 (YAGNI)

로그인, 서버, 기록 저장(로컬 저장 제외), 지도 SDK, 상대악력 등 카메라로 잴 수 없는 종목.
