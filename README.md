# 홈체력100 — 폰 카메라로 집에서 하는 국민체력100

**서비스 URL: https://kts6450.github.io/homefit100/**

스마트폰 카메라로 국민체력100 공식 측정 종목을 AI가 자동으로 세고, 국민체육진흥공단 체력인증센터 실제 측정결과와 비교해 **체력나이·백분위·예상 등급**과 **맞춤 운동처방**을 알려주는 웹 서비스입니다.
2026년 국민체육진흥공단 공공데이터 활용 경진대회(서비스 개발 부문) 출품작입니다.

## 주요 기능

- **AI 셀프 측정**: 브라우저에서 MediaPipe 자세추정을 실행해 관절을 인식하고 횟수를 자동으로 셉니다.
  - 19~64세: 교차윗몸일으키기 60초 (어깨–엉덩이–무릎 각도)
  - 65세 이상: 의자에앉았다일어서기 30초 (허벅지/정강이 세로비, 정면·측면 모두 가능)
- **운동 없이 체험**: 공단 공식 측정방법 영상을 같은 AI로 분석해 정확도를 보여줍니다.
- **체력나이 진단**: 같은 성별·나이 측정자 분포에서 백분위, 연령별 중앙값으로 체력나이, 등급별 중앙값으로 예상 등급을 계산합니다.
- **실제 처방 기반 추천**: 체력 수준이 비슷한 사람들이 센터에서 받은 운동처방 TOP5를 공식 운동 영상과 함께 보여줍니다.
- **체력인증센터 연결**: 사는 시·도의 센터를 최근 1년 측정건수 순으로 안내합니다.
- **개인정보 보호**: 카메라 영상은 기기 밖으로 전송되지 않습니다. 서버가 없습니다.

## 활용 공공데이터 (공공데이터포털, 서울올림픽기념국민체육진흥공단)

| 데이터 | 활용 |
|---|---|
| [국민체력100 체력인증센터 측정결과 정보](https://www.data.go.kr/data/15108938/openapi.do) | 성별×나이 규준표, 등급 기준, 운동처방(pres_note) 빈도 |
| [국민체력100 체력인증센터 측정건수 정보](https://www.data.go.kr/data/15114286/openapi.do) | 센터 위치·최근 1년 측정건수 |
| [국민체력100 동영상 정보](https://www.data.go.kr/data/15108846/openapi.do) | 측정방법 영상(AI 보정·데모), 운동처방 영상 |

측정방법·운동처방 영상 출처: 국민체육진흥공단 국민체력100 (공공누리 제1유형)

## 구조

```
scripts/fetch-data.mjs   공공데이터 API 원본 수집 (.env의 DATA_GO_KR_KEY 필요, data-raw/는 git 제외)
scripts/build-data.mjs   원본 → public/data/*.json 집계 (규준표·처방·영상·센터)
src/lib/repCounter.ts    히스테리시스 기반 반복 카운터
src/lib/norms.ts         백분위·체력나이·등급 계산
src/lib/pose.ts          MediaPipe PoseLandmarker 래퍼
src/components/          랜딩·프로필·측정·결과 화면
tests/                   Vitest 단위 테스트
```

## 실행

```bash
pnpm install
pnpm dev          # 개발 서버
pnpm vitest run   # 테스트
pnpm build        # 빌드 (public/data는 저장소에 포함되어 있어 API 키 없이 빌드 가능)
```

데이터를 새로 받으려면 `.env`에 `DATA_GO_KR_KEY=<공공데이터포털 인증키>`를 넣고 `node scripts/fetch-data.mjs && node scripts/build-data.mjs`를 실행합니다.

> 본 서비스의 결과는 참고용 자가 측정이며, 공식 체력인증은 국민체력100 체력인증센터에서 받을 수 있습니다.
